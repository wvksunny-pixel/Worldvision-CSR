# 월드비전 기업파트너십 제안 플랫폼

미팅에서 기업 담당자와 함께 클릭하며 쓰는 정적 웹사이트입니다. 빌드 과정 없이 파일만으로 동작합니다.

## 파일
- `index.html` — 배포·로컬 실행용 완성본 (GitHub Pages에 그대로 올리면 됩니다)
- `body.html` — 같은 내용의 원본 (Claude 아티팩트 게시용, `<html>`/`<head>` 태그 없음)
- `img/` — 통합제안서(260907)에서 추출한 사진
- `archive/` — 이전 버전

`index.html`은 `body.html`에 문서 머리말을 붙여 만든 파일입니다. 내용을 고칠 때는 `body.html`을 고친 뒤 `index.html`을 다시 만들거나, 두 파일을 똑같이 고쳐 주세요.

## 화면 구조 (사용자 여정: 관심 → 협력 범위 → 사례 → 전문성 → 분야 → 진행 방식 → 협업 제안)
- 상단 메뉴: 로고(HOME) · 협력 분야 `#explore` · 파트너십 사례 `#partners` · 월드비전 소개 `#strengths` · 자료실 `#library` · **협업 제안** CTA `#contact`
- HOME: Hero → 01 협력의 범위 → 02 파트너십 사례 → 03 왜 월드비전 → 04 협력 분야 → 05 진행 방식 → 다음 단계 → Footer
- 협업 제안 흐름(하위 단계 메뉴): 01 맞춤형 방향 찾기 `#test` → 02 협력 모델 설계 `#collab` → 03 내 제안서 `#proposal`(요약·출력 `#sheet`) → 04 문의하기 `#contact`
  - 01~03은 사이트 안에서 방향을 정리하는 탐색 도구, 04는 월드비전 공식 홈페이지 ‘기업후원 문의하기’로 연결(이 사이트에서 자동 접수 안 됨)
- 사업 상세 `#p-<사업id>`: 하단에 제안서 담기 · 협업 제안 · 관련 사례로 이어지는 다음 단계
- 발표자 모드: 상단 ‘발표자’ 스위치 또는 `P` 키. 상세 화면 단축키 `←` `→`, `S`
- 협업제안(사업 Pool·분류)과 참고자료 문서는 wvcsr.github.io/sk-wv-partnership 원문 데이터입니다. 참고자료 원문 페이지는 `assets/lib/<문서id>/`에 5쪽씩 이어 붙인 이미지로 들어 있습니다.

## 콘텐츠 수정
`body.html` 첫 번째 `<script>` 안의 데이터만 고치면 됩니다.
- `P` — 16개 사업. `int`(관심 분야), `modes`(협력 방식: 값은 제안서 근거 문구), `check`(내부 확인 필요 항목)
- `CASES` — 기업 협력 사례 (출처: 월드비전 파트너십 페이지)
- `INTERESTS`, `MODES` — 탐색 키워드
- 자료가 없는 값은 `null`로 두면 기업 화면에서는 숨고, 발표자 모드에서는 ‘내부 확인 필요’로 표시됩니다.

원칙: 사업명·수치·사례는 통합제안서와 공식 자료에 있는 그대로만 입력합니다.
