# 월드비전 기업파트너십 제안 플랫폼

미팅에서 기업 담당자와 함께 클릭하며 쓰는 정적 웹사이트입니다. 빌드 과정 없이 파일만으로 동작합니다.

## 파일
- `index.html` — 배포·로컬 실행용 완성본 (GitHub Pages에 그대로 올리면 됩니다)
- `body.html` — 같은 내용의 원본 (Claude 아티팩트 게시용, `<html>`/`<head>` 태그 없음)
- `img/` — 통합제안서(260907)에서 추출한 사진
- `archive/` — 이전 버전

`index.html`은 `body.html`에 문서 머리말을 붙여 만든 파일입니다. 내용을 고칠 때는 `body.html`을 고친 뒤 `index.html`을 다시 만들거나, 두 파일을 똑같이 고쳐 주세요.

## 화면
- `#home` 홈 · `#strengths` 한국월드비전 CSR의 강점 · `#explore` 사업 탐색 · `#p-<사업id>` 사업 상세 · `#collab` 협업제안 · `#test` 맞춤형 파트너십 테스트 · `#partners` 함께하는 기업 · `#library` 참고자료 · `#proposal` 맞춤형 제안 · `#sheet` 제안 요약(인쇄/PDF)
- 협업제안(사업 Pool·분류)과 참고자료(문서 목록)는 wvcsr.github.io/sk-wv-partnership 원문 데이터입니다. 참고자료 원문 페이지는 `assets/lib/<문서id>/`에 5쪽씩 이어 붙인 이미지(c01.jpg…)와 표지(cover.jpg)로 들어 있습니다.
- 맞춤형 파트너십 테스트의 문항·가중치·협력 아이디어는 `body.html`의 `Q`, `TYPES`, `IDEAS` 데이터에 있습니다. 아이디어는 ‘협력 제안 가능 분야’로만 표시됩니다.
- 발표자 모드: 상단 스위치 또는 `P` 키. 발표자 메모와 ‘확인 필요’ 항목은 이 모드에서만 보입니다.
- 상세 화면 단축키: `←` `→` 이전/다음 사업, `S` 핵심 요약
- 담은 사업과 제안 정보는 사용 중인 브라우저(localStorage)에만 저장됩니다.

## 콘텐츠 수정
`body.html` 첫 번째 `<script>` 안의 데이터만 고치면 됩니다.
- `P` — 16개 사업. `int`(관심 분야), `modes`(협력 방식: 값은 제안서 근거 문구), `check`(내부 확인 필요 항목)
- `CASES` — 기업 협력 사례 (출처: 월드비전 파트너십 페이지)
- `INTERESTS`, `MODES` — 탐색 키워드
- 자료가 없는 값은 `null`로 두면 기업 화면에서는 숨고, 발표자 모드에서는 ‘내부 확인 필요’로 표시됩니다.

원칙: 사업명·수치·사례는 통합제안서와 공식 자료에 있는 그대로만 입력합니다.
